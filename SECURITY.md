# Security policy

## Supported versions

pi-leash is pre-1.0 and not yet published. Security fixes are made only on the
latest development version; older commits and snapshots are not supported.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** private vulnerability reporting flow
for this repository. Do not disclose suspected vulnerabilities in public
issues, discussions, pull requests, logs, or chat transcripts.

Include enough detail to reproduce and assess the issue, such as the affected
revision, impact, prerequisites, and a minimal proof of concept. Remove or
redact credentials, tokens, private keys, environment values, personal data,
and any sensitive ACP messages. Use synthetic secrets when reproduction needs
credential-shaped input.

Maintainers will acknowledge and discuss the report through GitHub's private
reporting thread, assess severity and affected versions, and coordinate fixes
and disclosure there. Timing depends on impact and complexity; no fixed
response or remediation deadline is promised during the pre-1.0 phase.
